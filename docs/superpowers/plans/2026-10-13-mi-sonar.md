# mi-sonar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code / OpenCode skill (`mi-sonar`) that lets non-developer colleagues query the read-only `smartphone_market_data` PostgreSQL table and fetch MinIO originals through one bundled script, installable with one PowerShell line.

**Architecture:** Repo root = skill root. `scripts/query.py` is the only executable; it reads `sources/*.md` YAML headers to decide connection type (`postgres`/`s3`) and env var. `SKILL.md` tells the agent the workflow. `install.ps1` clones/pulls the repo into `~/.claude/skills/mi-sonar`, installs deps, `setx`es user-level env vars (inherited by both Claude Code and OpenCode), and junctions the folder into `~/.config/opencode/skill/mi-sonar`. Anything needing the company network is a separate handoff order for an in-company agent (Task 9).

**Tech Stack:** Python 3.10+, `psycopg[binary]` 3.x, `minio` 7.x, `pytest` (dev), `Pillow` (dev, banner only), PowerShell 5.1.

**Spec:** `docs/superpowers/specs/2026-10-13-mi-sonar-design.md`

## Global Constraints

- Python floor: 3.10 (colleague PCs). No syntax newer than 3.10.
- Runtime deps exactly: `psycopg[binary]`, `minio`. Nothing else in `requirements.txt`.
- All colleague PCs are Windows; console may be cp949. `query.py` must `reconfigure(encoding="utf-8", errors="replace")` stdout/stderr before printing.
- Env var names exactly: `MI_DB_SMARTPHONE` (postgres DSN), `MI_MINIO` (`http(s)://ACCESS:SECRET@host:port/bucket`).
- Row limits: default 200, hard max 5000. Query timeout 30000 ms.
- Guard rules fixed in code, no flag disables them: single statement, starts with SELECT/WITH, no `INSERT UPDATE DELETE DROP ALTER TRUNCATE GRANT REVOKE CREATE COPY` as whole words, read-only transaction.
- Never print a DSN, access key or secret. Error output shows exception class + message only.
- Exit codes: 0 ok, 1 connection/runtime error, 2 env var missing, 3 SQL rejected.
- Skill name `mi-sonar`. Skill folder on colleague PC: `~/.claude/skills/mi-sonar`. OpenCode junction: `~/.config/opencode/skill/mi-sonar`.
- Repo root is the skill root (clone target). `docs/` lives in the same repo.
- Commit messages end with the attribution lines given in the session's system reminder.

## Review Focus

1. `WHERE note = 'drop'` (forbidden word inside a string literal) → rejected with exit 3 and a message naming the word. Known false positive; documented in SKILL.md so the agent rewrites the literal. Test in Task 2.
2. SQL ending with `;` plus trailing whitespace/newline, or containing `-- comments` → accepted. Test in Task 2.
3. Result cells containing Korean / `|` / newlines / `None` → table prints without crashing on a cp949 console and without breaking markdown columns. Tests in Task 2 and Task 5.
4. `--limit 0`, `--limit -5` → rejected; `--limit 99999` → clamped to 5000 with a notice. Test in Task 3.
5. `MI_MINIO` secret containing `/`, `@`, `%` percent-encoded → parsed correctly via `unquote`. Test in Task 4.

```python
#!/usr/bin/env python
"""mi-sonar: read-only access to registered data sources for Claude/OpenCode agents.

Commands: sources | schema | sql | ls | fetch   (run with -h for usage)
"""
from __future__ import annotations

import argparse
import csv
import os
import re
import sys
from pathlib import Path
from urllib.parse import unquote, urlparse

SOURCES_DIR = Path(__file__).resolve().parent.parent / "sources"
DEFAULT_LIMIT = 200
MAX_LIMIT = 5000
TIMEOUT_MS = 30_000
LS_MAX = 200


class SonarError(Exception):
    """User-facing error. code: 1 runtime, 2 env missing, 3 SQL rejected."""

    def __init__(self, msg: str, code: int = 1):
        super().__init__(msg)
        self.code = code


# ---------- sources ----------

def parse_front_matter(text: str) -> dict:
    """Minimal YAML header parser: `key: value` and `key: [a, b]` only."""
    m = re.match(r"\s*---\s*\n(.*?)\n---", text, re.S)
    if not m:
        return {}
    out: dict = {}
    for line in m.group(1).splitlines():
        if ":" not in line or line.lstrip().startswith("#"):
            continue
        key, _, val = line.partition(":")
        val = val.strip()
        if val.startswith("[") and val.endswith("]"):
            out[key.strip()] = [v.strip() for v in val[1:-1].split(",") if v.strip()]
        else:
            out[key.strip()] = val
    return out


def load_sources(dir: Path = SOURCES_DIR) -> dict[str, dict]:
    sources: dict[str, dict] = {}
    for p in sorted(Path(dir).glob("*.md")):
        fm = parse_front_matter(p.read_text(encoding="utf-8"))
        name = fm.get("name") or p.stem
        fm["name"] = name
        fm["path"] = p
        sources[name] = fm
    return sources


def get_source(name: str, sources: dict | None = None) -> dict:
    sources = sources if sources is not None else load_sources()
    if name not in sources:
        raise SonarError(f"알 수 없는 소스: {name}. 사용 가능: {', '.join(sources) or '(없음)'}", 1)
    src = dict(sources[name])
    env = src.get("env", "")
    conn = os.environ.get(env, "")
    if not conn:
        raise SonarError(
            f"환경변수 {env} 가 설정되지 않았습니다. README의 설치 한 줄을 다시 실행하고 새 터미널을 여세요.",
            2,
        )
    src["conn"] = conn
    return src
```

```python
# ---------- SQL guard / output ----------

FORBIDDEN = re.compile(
    r"\b(INSERT|UPDATE|DELETE|DROP|ALTER|TRUNCATE|GRANT|REVOKE|CREATE|COPY)\b", re.I
)


def strip_comments(sql: str) -> str:
    sql = re.sub(r"/\*.*?\*/", " ", sql, flags=re.S)
    sql = re.sub(r"--[^\n]*", " ", sql)
    return sql.strip()


def check_sql(sql: str) -> str:
    """Return a cleaned single read-only statement or raise SonarError(code=3)."""
    s = strip_comments(sql)
    if s.endswith(";"):
        s = s[:-1].rstrip()
    if not s:
        raise SonarError("SQL이 비어 있습니다.", 3)
    if ";" in s:
        raise SonarError("SQL 문장은 하나만 허용됩니다 (세미콜론은 끝에 하나만).", 3)
    if not re.match(r"(?is)^(SELECT|WITH)\b", s):
        raise SonarError("SELECT 또는 WITH로 시작하는 조회만 허용됩니다.", 3)
    m = FORBIDDEN.search(s)  # ponytail: also hits words inside string literals; agent rewrites the literal
    if m:
        raise SonarError(
            f"허용되지 않는 키워드: {m.group(1).upper()} (문자열 안에 있다면 다른 표현으로 바꾸세요)", 3
        )
    return s


def _cell(v) -> str:
    if v is None:
        return ""
    return str(v).replace("\r", " ").replace("\n", " ").replace("|", "\\|")


def format_table(cols: list[str], rows: list[tuple]) -> str:
    head = "| " + " | ".join(_cell(c) for c in cols) + " |"
    sep = "| " + " | ".join("---" for _ in cols) + " |"
    body = ["| " + " | ".join(_cell(v) for v in r) + " |" for r in rows]
    if not body:
        body = ["(0 rows)"]
    return "\n".join([head, sep, *body])
```

```python
# ---------- postgres ----------

def connect_pg(dsn: str):
    import psycopg  # lazy: `sources` and unit tests run without the driver

    conn = psycopg.connect(dsn, options=f"-c statement_timeout={TIMEOUT_MS}", autocommit=False)
    conn.read_only = True
    return conn


def clamp_limit(n: int) -> tuple[int, str]:
    if n <= 0:
        raise SonarError("--limit 은 1 이상이어야 합니다.", 3)
    if n > MAX_LIMIT:
        return MAX_LIMIT, f"(--limit 이 최대값 {MAX_LIMIT} 으로 조정됨)"
    return n, ""


def run_sql(src: dict, sql: str, limit: int) -> tuple[list[str], list[tuple], bool]:
    stmt = check_sql(sql)
    with connect_pg(src["conn"]) as conn:
        with conn.cursor(name="mi_sonar") as cur:  # server-side cursor: never pulls the whole table
            cur.execute(stmt)
            rows = cur.fetchmany(limit + 1)
            cols = [d.name for d in cur.description]
    truncated = len(rows) > limit
    return cols, rows[:limit], truncated


def cmd_sql(src: dict, sql: str, limit: int, csv_path: Path | None) -> str:
    limit, notice = clamp_limit(limit)
    cols, rows, truncated = run_sql(src, sql, limit)
    parts = [format_table(cols, rows), f"({len(rows)} rows)"]
    if notice:
        parts.append(notice)
    if truncated:
        parts.append(
            f"결과가 {limit}행에서 잘렸습니다. SQL에서 집계(GROUP BY)하거나 --limit/--csv 를 사용하세요."
        )
    if csv_path:
        with open(csv_path, "w", newline="", encoding="utf-8-sig") as f:
            w = csv.writer(f)
            w.writerow(cols)
            w.writerows(rows)
        parts.append(f"CSV 저장: {csv_path}")
    return "\n".join(parts)


def cmd_schema(src: dict) -> str:
    from psycopg import sql as pgsql

    tables = src.get("tables") or []
    out = []
    with connect_pg(src["conn"]) as conn:
        with conn.cursor() as cur:
            if not tables:
                cur.execute(
                    "SELECT table_name FROM information_schema.tables "
                    "WHERE table_schema='public' ORDER BY 1"
                )
                tables = [r[0] for r in cur.fetchall()]
            for t in tables:
                cur.execute(
                    "SELECT column_name, data_type, is_nullable FROM information_schema.columns "
                    "WHERE table_name=%s ORDER BY ordinal_position",
                    (t,),
                )
                cols = cur.fetchall()
                out.append(f"## {t}\n" + format_table(["column", "type", "nullable"], cols))
                cur.execute(pgsql.SQL("SELECT * FROM {} LIMIT 3").format(pgsql.Identifier(t)))
                sample = cur.fetchall()
                out.append("샘플 3행:\n" + format_table([d.name for d in cur.description], sample))
    return "\n\n".join(out)
```

```python
# ---------- minio ----------

def parse_minio_url(url: str) -> dict:
    u = urlparse(url)
    bucket = u.path.strip("/")
    if u.scheme not in ("http", "https") or not u.username or not u.password or not u.hostname or not bucket:
        raise SonarError("MI_MINIO 형식은 http(s)://ACCESS:SECRET@host:port/bucket 이어야 합니다.", 2)
    endpoint = u.hostname + (f":{u.port}" if u.port else "")
    return {
        "endpoint": endpoint,
        "access": unquote(u.username),
        "secret": unquote(u.password),
        "bucket": bucket,
        "secure": u.scheme == "https",
    }


def connect_minio(url: str):
    from minio import Minio

    c = parse_minio_url(url)
    client = Minio(c["endpoint"], access_key=c["access"], secret_key=c["secret"], secure=c["secure"])
    return client, c["bucket"]


def cmd_ls(src: dict, prefix: str) -> str:
    client, bucket = connect_minio(src["conn"])
    rows = []
    for obj in client.list_objects(bucket, prefix=prefix, recursive=True):
        rows.append((obj.object_name, obj.size, str(obj.last_modified)[:19]))
        if len(rows) >= LS_MAX:
            break
    if len(rows) >= LS_MAX:
        tail = f"({len(rows)} objects, 최대 {LS_MAX}개까지만 표시. 접두어를 좁히세요)"
    else:
        tail = f"({len(rows)} objects)"
    return format_table(["key", "size", "modified"], rows) + "\n" + tail


def cmd_fetch(src: dict, key: str, out: Path | None) -> str:
    client, bucket = connect_minio(src["conn"])
    dest = Path(out) if out else Path.cwd() / Path(key).name
    dest.parent.mkdir(parents=True, exist_ok=True)
    client.fget_object(bucket, key, str(dest))
    return f"다운로드 완료: {dest}"
```

```python
# ---------- CLI ----------

def cmd_sources(sources: dict) -> str:
    rows = []
    for s in sources.values():
        env = s.get("env", "")
        state = "설정됨" if os.environ.get(env) else "미설정"
        rows.append((s["name"], s.get("kind", "?"), env, state, s.get("summary", "")))
    return format_table(["source", "kind", "env", "status", "summary"], rows)


def main(argv: list[str] | None = None) -> int:
    for stream in (sys.stdout, sys.stderr):
        try:
            stream.reconfigure(encoding="utf-8", errors="replace")
        except AttributeError:
            pass
    p = argparse.ArgumentParser(prog="query.py", description=__doc__)
    sub = p.add_subparsers(dest="cmd", required=True)
    sub.add_parser("sources", help="등록된 소스와 환경변수 상태")
    s = sub.add_parser("schema", help="테이블/컬럼/샘플 3행")
    s.add_argument("source")
    s = sub.add_parser("sql", help="읽기전용 SQL 실행")
    s.add_argument("source")
    s.add_argument("sql")
    s.add_argument("--limit", type=int, default=DEFAULT_LIMIT)
    s.add_argument("--csv", type=Path)
    s = sub.add_parser("ls", help="MinIO 객체 목록")
    s.add_argument("source")
    s.add_argument("prefix", nargs="?", default="")
    s = sub.add_parser("fetch", help="MinIO 객체 다운로드")
    s.add_argument("source")
    s.add_argument("key")
    s.add_argument("--out", type=Path)
    a = p.parse_args(argv)
    try:
        if a.cmd == "sources":
            print(cmd_sources(load_sources()))
            return 0
        src = get_source(a.source)
        if a.cmd == "schema":
            print(cmd_schema(src))
        elif a.cmd == "sql":
            print(cmd_sql(src, a.sql, a.limit, a.csv))
        elif a.cmd == "ls":
            print(cmd_ls(src, a.prefix))
        elif a.cmd == "fetch":
            print(cmd_fetch(src, a.key, a.out))
        return 0
    except SonarError as e:
        print(f"[mi-sonar] {e}", file=sys.stderr)
        return e.code
    except Exception as e:  # driver/network errors: class + message only, never the DSN
        print(f"[mi-sonar] {type(e).__name__}: {e}", file=sys.stderr)
        return 1


if __name__ == "__main__":
    sys.exit(main())
```

### Task 8: `install.ps1`

**Files:**
- Create: `install.ps1`

**Interfaces:**
- Consumes: `requirements.txt`, `scripts/query.py sources`
- Produces: idempotent installer. Parameters `-Repo`, `-Dest`, `-NoEnv` for local testing; `irm | iex` uses the defaults.

- [ ] **Step 1: Write `install.ps1`**

```powershell
<#
mi-sonar installer / updater (Windows, PowerShell 5.1+)
Colleagues:  powershell -ExecutionPolicy Bypass -c "irm __REPO_URL__/raw/main/install.ps1 | iex"
Local test:  .\install.ps1 -Repo C:\path\to\repo -Dest $env:TEMP\mi-sonar-test -NoEnv
#>
param(
    [string]$Repo = "__REPO_URL__",   # in-company agent fills: https://github.corp/org/mi-sonar
    [string]$Dest = (Join-Path $HOME ".claude\skills\mi-sonar"),
    [switch]$NoEnv
)
$ErrorActionPreference = "Stop"
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

# ---- connection info shared by the whole team (repo must stay private) ----
$EnvVars = @{
    MI_DB_SMARTPHONE = "__FILL_DSN__"     # postgresql://USER:PASSWORD@HOST:5432/DBNAME
    MI_MINIO         = "__FILL_MINIO__"   # http://ACCESS:SECRET@HOST:9000/BUCKET
}

function Step($msg) { Write-Host "[mi-sonar] $msg" -ForegroundColor Cyan }

# 1. get / update the skill folder
New-Item -ItemType Directory -Force (Split-Path $Dest) | Out-Null
if (Get-Command git -ErrorAction SilentlyContinue) {
    if (Test-Path (Join-Path $Dest ".git")) { Step "업데이트: git pull"; git -C $Dest pull --ff-only }
    else { Step "다운로드: git clone"; git clone --quiet $Repo $Dest }
} else {
    Step "git 없음: zip 다운로드"
    $zip = Join-Path $env:TEMP "mi-sonar.zip"
    Invoke-WebRequest "$($Repo -replace '\.git$','')/archive/refs/heads/main.zip" -OutFile $zip
    $tmp = Join-Path $env:TEMP "mi-sonar-unzip"
    if (Test-Path $tmp) { Remove-Item $tmp -Recurse -Force }
    Expand-Archive $zip $tmp
    if (Test-Path $Dest) { Remove-Item $Dest -Recurse -Force }
    Move-Item (Get-ChildItem $tmp | Select-Object -First 1).FullName $Dest
}

# 2. python deps
Step "Python 패키지 설치"
python -m pip install --quiet --disable-pip-version-check -r (Join-Path $Dest "requirements.txt")

# 3. user-level env vars (Claude Code and OpenCode both inherit these in a new terminal)
if (-not $NoEnv) {
    foreach ($k in $EnvVars.Keys) {
        if ($EnvVars[$k] -like "__FILL_*") { throw "install.ps1 의 $k 값이 아직 채워지지 않았습니다 (소유자에게 문의)." }
        setx $k $EnvVars[$k] | Out-Null
        Set-Item -Path "env:$k" -Value $EnvVars[$k]
    }
    Step "환경변수 등록: $($EnvVars.Keys -join ', ')"
}

# 4. register for OpenCode too (junction to the same folder)
$ocDir = Join-Path $HOME ".config\opencode\skill"
New-Item -ItemType Directory -Force $ocDir | Out-Null
$link = Join-Path $ocDir "mi-sonar"
if (-not (Test-Path $link)) { New-Item -ItemType Junction -Path $link -Target $Dest | Out-Null; Step "OpenCode 등록: $link" }

# 5. self-check
python (Join-Path $Dest "scripts\query.py") sources
Write-Host ""
Write-Host "설치 완료. 새 터미널을 열고 Claude 또는 OpenCode에게 'mi-sonar 설치 확인해줘' 라고 하세요." -ForegroundColor Green
```

Save the file as UTF-8 **with BOM** (PowerShell 5.1 reads Korean literals correctly only with a BOM).
