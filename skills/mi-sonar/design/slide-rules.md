# 자료(슬라이드) 작성 규칙

사내 보고 자료 1장을 만들 때 에이전트가 따르는 규칙. 말투는 `design/slide-tone.md` 를 따른다 (그 파일은 사내 비공개 레포에만 채워져 있음).

## 페이지 구성 (위→아래)

- 제목: 주제만 짧게 (예: `Smartwatch TAM`). 56px, navy `#0f1e3b`, 굵게.
- 제목 바로 아래 가로 선 1개 (2px navy). 제목은 선 위에 있다.
- 선 아래 쟁점 문장 1~2줄 (34px): 현재 상황 + 핵심 포인트 + 앞으로 볼 것. "…쟁점" 같은 표현 대신 "…모니터링 필요" 식으로 끝낸다. 이 문장이 페이지가 말하려는 바이며, 모든 그래프·bullet 은 이 문장을 뒷받침해야 한다.
- 아래는 좌/우 2분할 카드 (gap 40px). 카드 = 흰 배경, 1px `#dbe2eb` 테두리, 모서리 12px, 안쪽 여백 작게 (헤더 10px 20px, 본문 14px 20px).
- 카드 헤더: 옅은 회색 띠 `#f3f6fa` + 1px 아래선, 짧은 제목(완성 문장 아님, 28px, 중간 정렬). 예: `'26 YTD 지역 비중: 중국·아시아 48%, 성장 주도`.
- 카드 본문 순서: ① 핵심 bullet 2개 (28px, 맨 위) → ② 그래프 제목 `[ … ]` (28px, 중간 정렬, 위 10px 아래 6px 여백) → ③ 그래프 → ④ 범례 → (빈 공간) → ⑤ 출처 (24px, 회색 `#56647a`, 카드 맨 아래, 각 카드마다).
- 전체 푸터 없음. 출처는 카드 안에.

## 문장 규칙

- bullet 은 그 그래프로 말하려는 핵심 1가지씩. 성장 지역·성장 vendor 위주로 쓴다 (예: 중국·APAC). 부진 지역은 한 줄 이내.
- 줄바꿈은 의미가 바뀌거나 마침표·쉼표가 있는 곳에서만. 한 bullet 은 가능하면 한 줄(≤38자).
- 연도는 `'25`, `'26 YTD` 형식. 숫자 단위는 `Mu`(백만 대) 를 숫자 뒤에 붙인다: `150Mu`, `22Mu → 34Mu`. 비율은 `27%`, 증감은 `(+9%)`.
- 기간 비교는 "'26 YTD vs '25 동기" 처럼 출처 줄에 명시. 전망 숫자와 실적 숫자를 한 그래프에 섞지 않는다.
- 숫자가 없는 예시 자료는 출처에 `(예시값)` 을 쓴다.

## 그래프 규칙

- 색: 단색 블루 램프만 (아래→위 진한→연한) `#0b1733 #13275a #1b3a80 #2449a5 #2d5bc4 #3a6fd8`; 도넛 5조각은 `#0b1733 #1b3a80 #2449a5 #3a6fd8 #7fa3e8`. 막대 안 글씨는 흰색이므로 모든 구간이 흰 글씨 대비 4.5:1 이상인 색만 쓴다. 회색 램프 + 일부 강조도 허용하지만 한 자료 안에서 한 방식만.
- 누적 막대: 막대마다 합계 라벨을 위에 (`150Mu`), 구간마다 정수 라벨을 안에 (22px 흰색), 연도 라벨은 막대 아래 회색 선(1px `#dbe2eb`) 밑에. 합계·막대·연도는 같은 열에 정렬 (열 하나 = 세로 flex). 라벨이 안 들어가는 얇은 구간이 생기면 숫자를 바꾸지 말고 사용자에게 묻는다.
- 도넛: 바깥에 선 없이 조각 옆에 라벨 `중국 27%` / `(+9%)` 두 줄. 표는 따로 두지 않는다.
- 범례: 20px 정사각형(모서리 둥글지 않게) + 이름, 가로 한 줄.
- 글자 크기 단계: 56 / 34 / 28 / 24 / 22(막대 안) 만 쓴다.
- 폰트: 웹(Claude Slides)에선 Noto Sans KR, 사내 PPT 는 맑은 고딕, 외부 공개용은 Pretendard (`design/shadcn-navy-theme.css`).

## 예시

- `design/templates/smartwatch-tam.html`: 위 규칙을 전부 적용한 1장 (Claude Slides 슬라이드 형식, 1920×1080, 인라인 스타일). 새 자료는 이 파일 구조를 복사해 내용만 바꾼다.
- 데이터 집계 SQL: `sources/smartwatch.md` 의 `## 자료(슬라이드)용 집계`.
